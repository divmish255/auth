# Full-Stack Authentication System (Node.js + MongoDB + UI)

Features:
- Dual Identifier Registration (Email / Phone Number)
- OTP Verification (Twilio SMS Integration + Terminal Fallback)
- Password Hashing (bcryptjs)
- JWT Token Authentication
- Modern Responsive Glassmorphism UI (HTML/CSS/JS)

## How to Run:

1. Extract the ZIP file.
2. Open terminal in the extracted folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Make sure MongoDB is running locally, or set `MONGO_URI` environment variable.
5. Start the server:
   ```bash
   node server.js
   ```
6. Open browser and visit: `http://localhost:3000`
